A plug-in to maintain code across WordPress versions on TitanFusion.net

== Description ==

This plug-in will add any code necessary for TitanFusion.net to properly function. The intent is to maintain the
additional code across theme and WordPress version updates. Thus, preventing any functionality brakes.

The plug-in enables the following features.

* Use of SMTP email for hosts which do not allow email sent from the server or their network.
* Enable page resource caching, by the user browser, for content outside of the admin dashboard.
* Add Microsoft Clarity ID, as an alternative to Google Analytics.
* Disable WordPress native login and redirect to WordPress.com SSO via Automattic's Jetpack service plug-in.
